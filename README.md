# Rock Paper Scissors 🎮

A simple Rock Paper Scissors game built using Python.

## How to Play

The player chooses one of:

* Rock 🪨
* Paper 📄
* Scissors ✂️

The computer randomly selects one option, and the winner is decided according to the game rules.

## Features

* User input
* Random computer choice
* Input validation
* Score tracking
* Play multiple rounds

## Technologies Used

* Python

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the Python file:

```bash
python rock_paper_scissors.py
```

4. Follow the instructions displayed in the terminal.
